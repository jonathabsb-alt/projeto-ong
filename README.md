#  Plataforma Web para ONGs - [Caminhos Abertos]


##  Contexto e Objetivo Geral

Este projeto foi desenvolvido como plataforma web completa e profissional para uma ONG, aplicando, de forma integrada, todos os conceitos de Front-End. O objetivo é permitir à organização gerenciar atividades, divulgar projetos, captar recursos e engajar voluntários.

##  Tecnologias e Ferramentas

O projeto é baseado em tecnologias Front-End puras, priorizando desempenho e simplicidade:

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Estilização, Design System e Layout Responsivo (Mobile-First).
* **JavaScript:** Funcionalidades interativas e dinâmicas (máscaras, simulações).
* **Versionamento:** Git e GitHub (Versionamento e Infraestrutura Web).
* **Metodologia:** Kanban (Simulação de gestão ágil).

##  Estrutura de Arquivos e Funções

| Arquivo/Pasta | Tipo | Descrição e Funcionalidades |
| :--- | :--- | :--- |
| `index.html` | HTML | **Área Institucional:** Página inicial, missão, visão, equipe, contato e acesso rápido ao voluntariado. |
| `projetos.html` | HTML | **Gestão de Projetos e Voluntariado:** Exibição dinâmica de projetos (carrossel), portal de oportunidades e simulação da área do voluntário. |
| `cadastro.html` | HTML | **Sistema de Inscrição:** Formulário complexo para cadastro de voluntários, doadores e apoiadores. |
| `doacoes.html` | HTML | **Captação de Recursos:** Formulário de simulação de doação online com validação e feedback de sucesso. |
| `saibamais.html` | HTML | **Comunicação e Transparência:** Hub de notícias, área de imprensa e acesso à central de documentos. |
| `documentos.html` | HTML | **Transparência:** Simulação da central de documentos públicos e relatórios anuais. |
| `assets/css/style.css` | CSS | **Design System:** Estilos Mobile-First, Media Queries, Flexbox/Grid e garantia de contraste para acessibilidade. |
| `assets/scripts/script.js` | JavaScript | **Dinamismo:** Implementa máscaras de input, validações em tempo real, carrossel de projetos, progresso de doação e simulação de certificados. |
| `DOCUMENTACAO.md` | Documentação | Documentação técnica detalhada sobre o atendimento a requisitos de performance, SEO e acessibilidade. |
| `KANBAN.md` | Metodologia | **Simulação de Gestão Ágil:** Arquivo que será utilizado para mapear o fluxo de trabalho do desenvolvimento (To Do, Doing, Done). |

## ⚙️ Atendimento aos Objetivos Específicos

O projeto cobriu de forma prática todos os objetivos definidos na disciplina:

1.  **HTML5 Semântico:** Implementado nas 6 páginas, utilizando estruturas complexas e formulários.
2.  **CSS3 Avançado:** Aplicação de Design System, Flexbox, Grid e Media Queries responsivas.
3.  **JavaScript Dinâmico:** Implementação de carrossel, validações em tempo real, máscaras de input e simulações de dados (doação e histórico).
4.  **Versionamento e Infraestrutura:** Uso consistente de Git/GitHub e otimizações de SEO/Desempenho (Lazy Loading e meta tags).
5.  **Metodologias Ágeis:** Simulação de ambiente profissional através do versionamento por *commits* e do arquivo `KANBAN.md`.
6.  **Documentação:** Produção de documentação técnica de qualidade profissional (`README.md`).
